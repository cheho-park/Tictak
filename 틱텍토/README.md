# 삼목 게임

이 프로젝트는 HTML, CSS, JavaScript를 활용하여 제작한 간단한 삼목 게임(틱택토)입니다.  
모던한 디자인과 부드러운 인터랙션을 통해 사용자에게 깔끔한 게임 경험을 제공하도록 제작했어.

## 파일 구성

- **index.html**  
  게임의 기본 구조를 담당하며, 외부 CSS와 JavaScript 파일을 연동하는 역할을 해.
- **styles.css**  
  페이지의 전반적인 스타일과 모던한 디자인 요소(그라데이션, 카드 UI, 애니메이션 등)를 적용한 CSS 파일이야.
- **script.js**  
  게임 로직(플레이어 전환, 승리 조건 체크, 리셋 기능 등)을 구현한 JavaScript 파일이야.

## 사용 방법

1. 이 레포지토리를 클론하거나 다운로드합니다.
2. `index.html` 파일을 브라우저에서 열면 게임이 실행됩니다.
3. 각 셀을 클릭해 게임을 진행하고, **게임 리셋** 버튼으로 언제든지 게임을 초기화할 수 있습니다.

## 주요 기능

- **모던 디자인**:  
  Google Fonts의 'Roboto' 폰트를 사용해 깔끔한 타이포그래피와 그라데이션 배경, 부드러운 hover 효과 등 최신 디자인 트렌드를 반영했어.
- **반응형 인터랙션**:  
  CSS transition을 이용하여 셀 클릭 및 hover 시 부드러운 애니메이션 효과를 제공하며, 사용자 피드백을 강화했어.
- **간단한 게임 로직**:  
  JavaScript로 구현한 승리 조건 체크, 무승부 처리, 플레이어 전환 등 기본적인 삼목 게임 로직을 포함하고 있어.
